Full Semrush keyword list for thelpgco.pk, Pakistan database: **203 keywords, total volume 158,930, average KD 17%**.

| File | What it is |
|---|---|

| `semrush-keywords-2026-10-30.csv` | Clean version: keyword, intent, volume, kd_percent, cpc_usd, sorted by volume |
| `parse_semrush_paste.py` | Turns a new copy-paste into the CSV: `python parse_semrush_paste.py <raw.txt> <out.csv>` |
