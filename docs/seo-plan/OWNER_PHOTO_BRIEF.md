# Photo brief — every picture we need

**Rules (all shots):**
- Original photos only (your business, your stock, your office). No random stock “happy worker” images.
- Bright, sharp, upright. Phone is fine if steady and well lit.
- No faces unless that person gave written OK (partners, staff, customers).
- Prefer landscape for page heroes; close-ups for markings.
- Name files like: `lpg-cylinder-11-8kg-ogra-marking.jpg` (we convert to WebP later).
- One photo can power **many pages** — shoot the shared library first.

**Suggested shoot order:** Shared library → P1 money pages → cities → products → projects.
